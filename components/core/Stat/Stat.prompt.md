Stat — one proof metric. Use only for numbers that carry proof (results, duration, team size), 2–4 per row inside `.bn-cols`. Always say what was measured and, when it matters, the context in `note`.

```jsx
<div className="bn-cols bn-cols--3">
  <Stat value="3×" label="Wydajność planowania" note="Po 18 miesiącach" />
  <Stat value="8 lat" label="Czas współpracy" />
  <Stat value="6 → 40" label="Zespół" />
</div>
```
