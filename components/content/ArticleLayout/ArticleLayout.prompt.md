800px prose wrapper — put raw h2/p/ul/blockquote/code inside and it styles them. Place it inside a `.container` so it keeps the side gutter on mobile.

```jsx
<ArticleLayout>
  <h2>Punkt wyjścia - Architektura Bólu</h2>
  <p>…</p>
  <blockquote>„…” – Dyrektor Operacyjny</blockquote>
</ArticleLayout>
```
